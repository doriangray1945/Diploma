# Semantic concept → filter mappings (для генератора)

Reference для GPT-4 generator. Эти mappings — то, чему модель учится через
обучающие примеры. В schema-описаниях и в backend конкретные семантические
связки **не хардкодятся** — они только в training data.

## Multi-value поля

`material` и `color` — **массивы**. `category` и `price_level` — single.

## Material: концепт → array

| User says | material array |
|---|---|
| мягкое, уютное, тёплое, плюшевое | `["ткань", "кожа"]` |
| твёрдое, прочное, надёжное, долговечное | `["дерево", "металл"]` |
| натуральное, экологичное, эко | `["дерево", "ткань", "кожа"]` |
| современное, индустриальное, лофт | `["металл"]` (+ search="лофт" если нужно) |
| прозрачное, лёгкое визуально | `["стекло"]` |
| кожаное | `["кожа"]` |
| тканевое, обивка | `["ткань"]` |
| металлическое, железное | `["металл"]` |
| деревянное | `["дерево"]` |
| пластиковое | `["пластик"]` |

**Конкретные сорта** (дуб, сосна, бук, велюр, рогожка) → `material: ["дерево"]` или `["ткань"]` + конкретный сорт в `search`.

Пример:
- «дубовый стол» → `{material: ["дерево"], search: "дуб"}`
- «велюровый диван» → `{material: ["ткань"], search: "велюр"}`

## Color: концепт → array

| User says | color array |
|---|---|
| красный, алый | `["Красный"]` |
| красные ИЛИ синие | `["Красный", "Синий"]` |
| тёмный | `["Чёрный", "Венге", "Коричневый"]` |
| светлый | `["Белый", "Бежевый", "Серый"]` |
| яркий, сочный | `["Красный", "Жёлтый", "Зелёный", "Изумрудный"]` |
| нейтральный, спокойный | `["Бежевый", "Серый", "Белый"]` |
| тёплый | `["Красный", "Жёлтый", "Коричневый", "Орех"]` |
| холодный | `["Синий", "Зелёный", "Изумрудный"]` |

Цвета **точно из COLORS enum** (с заглавной буквы): Бежевый, Белый, Венге, Жёлтый, Зелёный, Изумрудный, Коричневый, Красный, Орех, Прозрачный, Розовый, Серый, Синий, Чёрный.

## Price (single)

| User says | filter |
|---|---|
| недорогое, бюджетное, дешёвое, доступное, эконом | `price_level: "budget"` |
| среднее по цене, средний сегмент | `price_level: "mid"` |
| дорогое, премиум, премиальное, элитное, дизайнерское, люкс | `price_level: "premium"` |
| **конкретное число** «до 50000», «от 20к» | `min_price` / `max_price` (число) |

Не смешивать price_level с min/max_price.

## Category (single или пусто)

| User says | category |
|---|---|
| диван, диванчик | `"Диваны"` |
| кресло | `"Кресла"` |
| стол, столик | `"Столы"` |
| стул, табурет | `"Стулья"` |
| шкаф, шкафчик | `"Шкафы"` |
| кровать, кроватка | `"Кровати"` |
| «на чём есть», «обеденная мебель» | `"Столы"` |
| «на чём сидеть» | `"Стулья"` или `"Кресла"` |
| «на чём спать» | `"Кровати"` |
| «куда сложить вещи» | `"Шкафы"` |
| «мебель» (без уточнения) | category пропущен |

## Search (single string — стиль/назначение)

Когда характеристика **не покрывается** другими полями:

- лофт, индустриальный, скандинавский, итальянский, классический, минималистичный
- детский, для ребёнка → `search: "детский"`
- офисный, рабочий → `search: "офисный"`
- угловой, складной, раскладной → `search: "угловой"` / etc.
- компактный, маленький, большой, просторный
- элегантный, стильный
- дубовый/сосновый и т.п. конкретные сорта

## Quantifier (для add/remove)

| User says | quantifier |
|---|---|
| все, всё, каждый | `"all"` |
| первые N | `"first_n"` + `n: N` |
| последние N | `"last_n"` + `n: N` |
| остальные, оставшиеся, прочие | `"remaining"` |

## Multi-step actions

Запросы с несколькими действиями = **отдельный шаг на каждое**.

- «найди X и сохрани все в избранное» → `[apply_filters, add_to_favorites(quantifier=all)]`
- «найди X и положи в корзину по N и в избранное» → 3 шага: `[apply_filters, add_to_cart(qty=N), add_to_favorites]`
- «первые 3 в корзину, остальные в избранное» → `[add_to_cart(first_n,3), add_to_favorites(remaining)]`
- «убери диваны из корзины и очисти избранное» → `[remove_from_cart, clear_favorites]`

## Out-of-scope / answer_only

- Приветствия, благодарности → `plan: []`
- «оформи заказ», «открой карточку» (вне V1) → `plan: []`
- «что в избранном» → `[get_favorites]`
- «что в корзине» → `[get_cart]`

## Typos

Модель **исправляет** опечатки в начальную форму:
- «крсный» → `color: ["Красный"]`
- «дванчик» → `category: "Диваны"`
- «деревяный» → `material: ["дерево"]`
- «бюжетный» → `price_level: "budget"`
